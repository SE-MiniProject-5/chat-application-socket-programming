# Chat Application using Socket Programming

A real-time chat application developed using socket programming and WebSockets
for instant messaging between users.

## Project Overview

This project aims to develop a real-time chat application that allows users
to communicate through instant text messaging using WebSocket-based
communication.

## Features

- User registration and authentication
- Real-time messaging
- WebSocket-based communication
- Chat history
- Online/offline status
- Secure communication
